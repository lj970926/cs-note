在 bash 中，一行写多个命令主要靠命令连接符，区别在于**是否关心前一个命令的退出码**。

## `;` —— 顺序执行，不管成败

```bash
command1 ; command2 ; command3
```

依次执行，即使 `command1` 失败，后面的命令也会继续执行。等价于换行写三条命令。

```bash
echo "start" ; ls ; echo "end"
```

## `&&` —— 前一个成功才执行下一个

```bash
command1 && command2
```

只有 `command1` 的退出码为 0（成功）时，才执行 `command2`。常用于"先编译，成功了再运行"：

```bash
mkdir build && cd build && cmake .. && make -j
```

## `||` —— 前一个失败才执行下一个

```bash
command1 || command2
```

`command1` 失败（退出码非 0）时，才执行 `command2`。常用于兜底或打印错误信息：

```bash
git pull || echo "pull failed"
```

经典用法是成功/失败分别处理：

```bash
cmd1 && echo "ok" || echo "fail"
```

## `&` —— 后台并发执行

```bash
command1 & command2
```

把 `command1` 放到后台执行，立即继续执行 `command2`，二者**并发**，不是顺序。

```bash
./long_task.sh & echo "started in background"
```

## `|` —— 管道，传递输出

```bash
command1 | command2
```

把 `command1` 的 stdout 作为 `command2` 的 stdin，二者通常同时运行：

```bash
cat file.txt | grep "error" | wc -l
```

## 分组：`{}` 与 `()`

组合多条命令时可以分组：

```bash
mkdir build && cd build && { cmake .. && make -j; }
```

- `{ ...; }`：在**当前 shell** 中分组。注意花括号两边要有空格，最后一条命令后要有分号或换行。
- `(...)`：在**子 shell** 中执行，不影响当前 shell 的目录和变量：

  ```bash
  (cd build && cmake .. && make -j)  # 执行完当前目录不变
  ```

## 速查表

| 需求 | 写法 |
|------|------|
| 无论成败依次执行 | `cmd1 ; cmd2` |
| 前一个成功才执行下一个 | `cmd1 && cmd2` |
| 前一个失败才执行下一个 | `cmd1 \|\| cmd2` |
| 后台并发跑 | `cmd1 & cmd2` |
| 前一个输出传给下一个 | `cmd1 \| cmd2` |
| 成功/失败分别处理 | `cmd1 && echo ok \|\| echo fail` |

最常用的是 `&&`，它能保证前一步成功才继续，避免错误连锁反应。
