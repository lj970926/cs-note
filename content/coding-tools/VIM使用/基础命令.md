按模式组织的 Vim 常用命令速查。`<C-x>` 表示 Ctrl+x，`{motion}` 表示任意移动命令（如 `w`、`$`、`G`）。

## 普通模式

### 光标移动

| 按键 | 作用 |
| --- | --- |
| `h` `j` `k` `l` | 左 / 下 / 上 / 右移动一个字符 |
| `w` / `b` / `e` | 下一个单词开头 / 上一个单词开头 / 单词结尾 |
| `0` / `^` / `$` | 行首 / 行首第一个非空白字符 / 行尾 |
| `f{char}` / `t{char}` | 查找行内字符的下一个出现位置，`f` 停在字符上，`t` 停在字符前一个位置 |
| `F{char}` / `T{char}` | `f` / `t` 的反向查找 |
| `[number]G` | 跳转到指定行，缺省跳转到尾行（`gg` 跳回首行） |
| `<C-^>` | 在当前缓冲区和上一个缓冲区之间快速切换 |
| `zz` | 重绘屏幕并令当前行居中 |

### 编辑与删除

| 按键 | 作用 |
| --- | --- |
| `x` / `X` | 删除当前字符 / 向前删除一个字符 |
| `s` | 删除当前字符并进入插入模式 |
| `dd` / `yy` / `p` | 删除（剪切）整行 / 复制整行 / 粘贴 |
| `c{motion}` | 删除从当前位置到 motion 指示位置的内容，并进入插入模式 |
| `C` | 等价于 `c$`，删至行尾并进入插入模式 |
| `S` | 等价于 `cc`，删除整行并进入插入模式 |
| `I` | 等价于 `^i`，在行首第一个非空白字符前插入 |
| `daw` | 删除当前光标所在的单词以及开头或结尾的空格 |
| `J` | 连接两行，去掉换行符 |
| `r{char}` | 替换光标下的单个字符（不进入插入模式） |
| `R` | 进入替换模式 |
| `gR` | 进入虚拟替换模式：按屏幕实际显示宽度替换字符，而不是按文件中保存的字符替换，可避免 tab 替换导致的行宽显示变化 |
| `u` / `<C-r>` | 撤销 / 重做 |
| `gU{motion}` | 将范围内的字符变为大写（`gu` 为变小写） |
| `<C-a>` / `<C-x>` | 将光标处或光标后的第一个数字加一 / 减一 |

### 进入可视模式

| 按键 | 作用 |
| --- | --- |
| `v` | 面向字符的可视模式 |
| `V` | 面向行的可视模式 |
| `<C-v>` | 面向列块的可视模式 |

## 插入模式

| 按键 | 作用 |
| --- | --- |
| `<C-h>` | 删除前一个字符（同退格键） |
| `<C-w>` | 删除前一个单词 |
| `<C-u>` | 删至行首 |
| `<C-o>` | 进入普通-插入模式：执行一条普通模式命令后自动回到插入模式 |
| `<C-r>{register}` | 粘贴寄存器 register 中的内容 |
| `<C-r>=` | 调出表达式寄存器，可计算表达式并插入结果 |

## 可视模式

| 按键 | 作用 |
| --- | --- |
| `o` | 切换高亮选区的活动端 |
| `gv` | 重选上次的高亮选区 |

## 命令行模式

### 基础

| 命令 | 作用 |
| --- | --- |
| `:{number}` / `:$` | 跳转到指定行 / 跳转到行尾 |
| `:print`（`:p`） | 打印当前行，`:[range]print` 打印指定范围的行 |
| `@:` | 重复上次的 Ex 命令 |
| `<C-r><C-w>` | 将当前光标下的单词复制到命令行 |
| `q:` | 打开命令行窗口，可编辑历史命令 |
| `:!{command}` | 执行 shell 命令 |
| `:shell` | 打开一个交互式 shell，输入 `exit` 退出 |

### 行操作

| 命令 | 作用 |
| --- | --- |
| `:[range]t{address}` | 将 range 内的行**复制**到 address 指示的位置 |
| `:[range]m{address}` | 将 range 内的行**移动**到 address 指示的位置 |
| `:[range]normal {command}` | 对范围内每一行执行一条普通模式命令 |

### 缓冲区与参数列表

| 命令 | 作用 |
| --- | --- |
| `:ls` | 展示缓冲区列表 |
| `:buffer N` | 跳转到编号为 N 的缓冲区 |
| `:bdelete N1 N2 N3`（`:bd`） | 删除编号为 N1、N2、N3 的缓冲区 |
| `:M,Nbdelete` | 删除 M 到 N 范围内的所有缓冲区 |
| `:bprev`（`:bp`） / `:bnext`（`:bn`） | 切换到缓冲区列表的上一个 / 下一个 buffer |
| `:prev` / `:next` | 切换到参数列表的上一个 / 下一个文件 |
