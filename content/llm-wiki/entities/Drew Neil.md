# Drew Neil

## Definition

Drew Neil 是 Vim 专家和作家，以《Practical VIM》一书闻名。他长期通过 vimcasts.org 等渠道分享 Vim 高效编辑技巧。

## Known works

- *Practical VIM* — Vim 高效编辑指南
- vimcasts.org — Vim 教程视频/文章
