# Vim

## Definition

Vim（Vi IMproved）是一款高度可扩展的模态文本编辑器，以键盘驱动的高效编辑著称。它是 Vi 的增强版，支持多种模式（普通模式、插入模式、可视模式、命令行模式等）、宏、插件和高度自定义配置。

## Key ideas

- **Modal editing**：不同模式做不同事，手指不离开主键区。
- **Composability**：操作符（operator）+ 动作（motion）组合成强大命令。
- **Repeatability**：用 `.` 重复上一次修改，是效率核心之一。
- **Extensibility**：通过插件和配置适应各种语言和工作流。
