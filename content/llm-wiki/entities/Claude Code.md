# Claude Code

## Definition

Claude Code 是 Anthropic 推出的官方 CLI 版 AI 编程助手，允许用户在终端中通过自然语言与 Claude 交互，读取、编辑、运行代码，调用工具并执行多步骤工程任务。

## Attributes

| 属性 | 说明 |
|---|---|
| 厂商 | Anthropic |
| 形态 | 命令行工具（CLI），也提供桌面与 IDE 扩展 |
| 核心能力 | 代码理解、编辑、测试、调试、工具调用、多 agent 编排 |
| 关键原语 | `/goal`、 `/loop`、 `/schedule`、skills、workflows |
| 相关模型 | Claude 系列（Claude Opus/Sonnet/Haiku 等） |
