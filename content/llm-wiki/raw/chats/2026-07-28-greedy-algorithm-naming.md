# Chat: 贪心算法为什么叫贪心

> 2026-07-28 Claude Code 会话存档。本文件为原始材料，归档后不再修改。

## Q

你能讲讲贪心算法为啥要叫贪心吗？

## A

"贪心"（greedy）这个名字非常形象：它描述的是算法做决策的方式——**每一步都只拿眼前看起来最好的那个选择，绝不回头，也不为将来打算**，就像一个贪心的人看到好处就立刻抓在手里。

### 具体怎么"贪"

以求解问题的过程为例，贪心算法把问题拆成一系列决策点，在每个决策点：

1. 只看**当前**这一步哪个选择局部最优（比如面值最大的硬币、权重最大的边、结束最早的活动）
2. 立刻选定它，**做出后不再撤销、不再反悔**
3. 进入下一步，继续贪

经典例子是找零钱：要凑 36 元，贪心策略是每次都拿不超过剩余金额的最大面额——先拿 20，再拿 10，再拿 5，再拿 1。每一步都是"眼前能拿的最大好处"。

### 为什么这个名字贴切

"贪心"隐含了两层含义，恰好对应算法的两个特点：

- **短视（只顾眼前）**：它不考虑这一步选择对后续的影响。这既是它快的原因（不用像动态规划那样枚举所有子问题），也是它的风险所在——很多问题上局部最优拼不出全局最优。
- **不知足 / 不回头**：一旦做了选择就锁死，没有回溯机制。这和回溯算法形成鲜明对比，回溯是"发现走错了就退回来换条路"，贪心是"一条路走到底"。

### 什么时候"贪"能成功

贪心得正果的前提是问题满足**贪心选择性质**：局部最优选择能导向全局最优解（通常还配合最优子结构）。典型如：

- 哈夫曼编码（每次合并频率最低的两个节点）
- 最小生成树的 Kruskal / Prim（每次拿权最小的安全边）
- 活动选择问题（每次选结束最早的活动）

反例是背包问题（0-1 背包）：按"单位重量价值最高"贪心地装，往往得不到最优解，必须用动态规划。

所以这个名字既是描述，也是警告：**贪心地做决策很简单很快，但你得先证明这个问题上"贪"是对的**。
