# src-gtd

## One-line summary

[[entities/David Allen|David Allen]] 提出的任务管理方法论 GTD 的完整指南：把所有悬而未决的事务外化到可信赖的外部系统，通过收集→理清→组织→回顾→执行五步流程让大脑从"记挂"中解放出来。

## Key claims

1. 核心理念：大脑是用来思考的，不是用来记忆的；"悬而未决"（Open Loop）持续占用大脑内存，是焦虑的主要来源。
2. 五步流程：收集（Capture，不遗漏不判断）→ 理清（Clarify，决策树分派）→ 组织（Organize，六类清单）→ 回顾（Reflect，系统的发动机）→ 执行（Engage，按情境选择）。
3. 理清决策树：可行动吗 → 2 分钟内能完成则立刻做；需要别人做则委派进"等待中"；否则进"下一步行动"。不可行动的分为参考资料 / 将来也许 / 删除。
4. "下一步行动"黄金法则：必须是动词开头的下一个物理可见动作（✅"给张三发邮件问报价"，❌"处理项目 A"）。
5. 清单体系六类：日程表、下一步行动、项目（任何需 2+ 行动的事）、等待中、将来/也许、参考资料。
6. 上下文（Context）分组是精髓：按"我在什么情境下能做"（@电脑/@电话/@外出…）而非按项目分组，因为任何时刻的选择依据是"我现在有什么资源"。
7. Weekly Review 不是整理清单，而是**重新建立对系统的信任**；信任建立后大脑才停止焦虑。不做回顾系统就会腐烂。
8. 执行用四维度筛选：情境、时间、精力、优先级；GTD 不教"先做重要的事"，教"根据当下情境选择行动"。
9. 常见陷阱：收集癖、过度拆解、系统过度复杂、跳过回顾、上下文过多（控制在 5-7 个）、只列任务不定义 Next Action。
10. 工具映射：Todoist（Inbox + 标签上下文 + 过滤器）、嘀嗒清单（收集箱 + 日历视图）；GTD 解决"不遗漏、减焦虑"，高效产出需结合深度工作等方法。
