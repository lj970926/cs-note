# src-practical-vim

## One-line summary

[[entities/Drew Neil|Drew Neil]] 的《Practical VIM》强调：高效使用 [[entities/Vim|Vim]] 的关键是构造**可重复的修改**，善用 `.` 命令、操作符命令、Ex 命令和宏。

## Source

- Vault note: [[book-notes/Practical VIM]]
- Book: *Practical VIM* by [[entities/Drew Neil|Drew Neil]]

## Key claims

1. 构造可重复的修改是高效使用 Vim 的核心。
2. 能用操作符命令时，优先于可视命令。
3. 把撤销单元切成合适大小的块，便于回退。
4. 善用 Ex 命令（如 `:t`、`:m`、`:normal`）在范围上批量操作。
5. 缓冲区列表、历史命令、Shell 命令集成都是日常高频工作流。
