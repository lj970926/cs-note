# src-procrastination-handbook

## One-line summary

一份可操作的拖延应对手册：核心观点是**拖延是情绪管理问题而非时间管理问题**，先诊断类型（完美主义/瘫痪/混沌），再从启动、拆解、环境、情绪、维持五个层面对症下药。

## Key claims

1. 拖延的本质是逃避任务勾起的情绪（怕做不好、任务太大、觉得无聊），纯效率技巧治不好，要从情绪和启动机制下手。
2. 三种拖延类型共用一个症状但解法不同：完美主义型 → 允许烂开始；瘫痪型 → 拆解与时间盒；混沌型 → 大脑倾倒 + GTD。
3. 拖延的阻力约 90% 集中在"启动"：两分钟规则、缩小到不可能失败、五秒启动法都是降低启动成本的手段。
4. 任务越具体启动阻力越小："下一步行动化"要求把任务改写成下一个物理动作；用时间盒（固定时段投入）代替结果盒（不可控的产出目标）。
5. 意志力是消耗品，靠环境设计替代：降低好习惯摩擦力、增加坏习惯摩擦力、固定深度时段。
6. 拖延后的自责会制造下一次拖延（情绪更差 → 更想逃避）；可以复盘，禁止自我鞭打。
7. 防复发两件套：睡前大脑倾倒（写下来大脑才肯"关机"）+ 记录而不评判（两周后模式自然浮现）。
8. 书单按层次递进：《拖延心理学》（诊断）→《微习惯》（战术）→《原子习惯》（系统）→《自控力》（机制）；另有《搞定》(GTD) 治混沌型、《深度工作》治瘫痪型。
9. 最小起步方案只有三件事：写下今天最重要的一件事 → 定固定时间盒 → 开始时只做两分钟；方法一次上太多本身就是新的拖延来源。
