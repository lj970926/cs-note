# Mermaid 使用指南

> Source: [[language/mermaid/Mermaid 使用指南]]

## One-line summary

Mermaid 是基于文本的图表绘制工具，通过 Markdown 风格的代码块生成流程图、时序图、类图、状态图、饼图、甘特图、ER 图、思维导图、象限图和 Git 图。

## Key claims

- 在 Obsidian 等支持环境中使用 ` ```mermaid ` 代码块即可渲染。
- 主要图表类型：Flowchart、Sequence Diagram、Class Diagram、State Diagram、Pie、Gantt、ER、Mindmap、Quadrant Chart、Gitgraph。
- 类图中需区分组合、聚合、关联、依赖的语义与 C++ 实现差异。
- 常见实践：中文节点用引号包裹、复杂图表可考虑 Excalidraw 或 Mermaid Live Editor。
