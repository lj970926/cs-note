# 算法导论 (CLRS) 阅读路线

> 《Introduction to Algorithms》(CLRS, 3rd ed.) 共 35 章，不建议从第一页线性啃到最后。按"地基 → 核心 → 进阶 → 选读"分层推进，配合做课后题。

## 阶段 1：地基——数学与基础概念（Ch 1–5）

约 1–2 周，必学。

- **Ch1 算法在计算中的作用**——建立感觉，通读即可
- **Ch2 入门**——插入排序、归并排序、伪代码与循环不变式（整本书的"语法"）
- **Ch3 函数增长**——O / Ω / Θ 记号，必须吃透
- **Ch4 分治与递归式**——主定理，后面每章都在用
- **Ch5 概率分析与随机算法**——数学吃力可先跳过概率部分，等到 Ch11 散列 / 随机快排再回来补

## 阶段 2：核心——排序、数据结构与设计范式（Ch 6–16）

约 4–6 周，全书最核心，**课后题至少做奇数题**。

- **Ch6 堆排序**
- **Ch7 快速排序**
- **Ch8 线性时间排序**（计数 / 基数 / 桶排序）
- **Ch9 中位数与顺序统计量**
- **Ch10 基本数据结构**（栈 / 队列 / 链表 / 有根树）
- **Ch11 散列表**
- **Ch12 二叉搜索树**
- **Ch13 红黑树**
- **Ch14 数据结构的扩张**（区间树等）
- **Ch15 动态规划**
- **Ch16 贪心算法**

Ch17 摊还分析可作为选读。

## 阶段 3：进阶——图算法与高级专题（Ch 22–26, Ch 21）

约 4–6 周，按需深入。顺序就是按依赖排的：

- **Ch22 基本图算法**——BFS / DFS、拓扑排序、强连通分量
- **Ch23 最小生成树**——Kruskal / Prim，配合 Ch21 并查集
- **Ch24 单源最短路径**——Bellman-Ford / DAG 松弛 / Dijkstra
- **Ch25 所有节点对最短路径**——Floyd-Warshall / Johnson
- **Ch26 最大流**
- **Ch21 不相交集合**（并查集）——建议配合 Ch23 一起读

## 阶段 4：选读——按方向深挖（Ch 18–20, 27–35）

不必全读，挑与自己相关的：

- **系统 / 工程方向**：Ch18 B 树、Ch19 二项堆 / 斐波那契堆、Ch20 van Emde Boas 树
- **ML / 数据方向**：Ch28 矩阵运算、Ch29 线性规划、Ch31 数论（RSA）
- **理论 / 算法方向**：Ch32 字符串匹配、Ch33 计算几何、Ch34 NP 完全性、Ch35 近似算法
- **并行 / 数值**：Ch27 多线程算法、Ch28–29

## 阅读建议

1. **不要线性读**。第 1 阶段快过，Ch3 / Ch4 必须扎实；第 2 阶段是重头戏。
2. **必须做题**。只看不做等于没读。课后题卡住可查 [CLRS Solutions](https://walkccc.me/CLRS/)，但先自己想 30 分钟。
3. **动手实现**。用 Python / C++ 实现每个核心算法，比抄伪代码有效。
4. **配套资源**：MIT 6.006 / 6.046 公开课与 CLRS 章节高度对应（Leiserson 本人讲）。
5. **节奏参考**：每周 1–2 章 + 做题，前 3 阶段约 3 个月。
