# 单调栈

单调栈是一种在栈中维护单调序列的数据结构。遍历到新元素时，把已经不可能成为答案的栈顶元素弹出；因此每个元素最多入栈、出栈一次，整体复杂度通常是 $O(n)$。

## 适合的题目

### 1. 查找最近的更大或更小元素

常见问法是：对每个元素，找它左边或右边第一个满足大小关系的元素。

- 下一个更大元素、下一个更小元素
- 每日温度
- 股票价格跨度
- 左侧/右侧最近的更大或更小元素

### 2. 确定元素能够扩展到的区间边界

这类题通常需要计算每个元素左、右两边第一个更小或更大的位置。

- 柱状图中的最大矩形
- 最大矩形
- 子数组最小值之和
- 子数组最大值之和

### 3. 维护单调子序列并做贪心选择

当较大的数会阻碍后续得到更优答案时，可以弹出栈顶元素。

- 删除 $k$ 个数字得到最小数
- 保留字典序最小或最大的子序列
- 移除不必要元素，使剩余序列保持最优

## 识别特征

看到下面的组合时，应考虑单调栈：

> 对每个元素，寻找左右两侧最近的、更大/更小的元素；暴力做法需要向左或向右反复扫描，复杂度可能是 $O(n^2)$；而某些元素一旦被当前元素淘汰，就永远不可能再成为答案。

## 维护方式

通常栈中保存下标，而不是只保存数值，因为下标还可以用来计算距离和区间宽度。

- 从栈底到栈顶递减：适合寻找最近的更大元素
- 从栈底到栈顶递增：适合寻找最近的更小元素
- 是否弹出相等元素，要根据题目要求区分严格关系和非严格关系

例如，从左到右寻找左侧最近的严格更大元素：

```cpp
for (int i = 0; i < n; ++i) {
    while (!st.empty() && a[st.top()] <= a[i]) {
        st.pop();
    }

    // st.top() 是左侧最近的严格更大元素（如果存在）
    st.push(i);
}
```

寻找右侧最近元素时，通常从右向左扫描；其余逻辑类似。

## 与其他结构的区别

- 滑动窗口最大值/最小值需要从队首和队尾删除元素，通常使用单调队列
- 需要动态维护全局最大值/最小值时，通常使用堆
- 需要任意区间查询时，通常考虑线段树、树状数组或 RMQ

## 一句话判断

> “最近的、更大/更小的、左右边界、每个元素只处理一次”——看到这些关键词，就应该想到单调栈。
